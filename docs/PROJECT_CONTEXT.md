# FSquaro Website Project Context

## Brand and purpose

FSquaro is an Indian fashion jewellery and accessories brand. This project is the official FSquaro brand website: a premium, modern, responsive experience that presents the brand and its product catalogue.

## Product scope

- The website is a brand and product-catalogue experience, not a complete e-commerce checkout platform.
- Product purchase actions will redirect visitors to verified external marketplaces.
- Product prices must not be displayed.
- Product search is required in the first release.
- Product information will begin as local, structured data.

## Technical foundation

- Next.js with the App Router
- React
- TypeScript in strict mode
- Tailwind CSS
- Lucide icons when icons are needed

## Experience requirements

- Support light and dark themes.
- Preserve a modern-brand direction: clean, professional, spacious, and premium.
- Use the official FSquaro logo assets only when they are supplied. Do not recreate or alter the logo.

## Current phase

This phase establishes the project foundation only. Homepage design approval is pending, so no FSquaro homepage sections, visual treatments, or independent design choices are implemented yet.
